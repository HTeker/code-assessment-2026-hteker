# Parent-Teacher Conferences Service

Take-home assignment (see ASSIGNMENT.md, originally README.md): a small TypeScript backend that lets a teacher set up a conference evening (time slots generated from date/start/end/duration) and lets parents book, move and cancel slots for their children. Timebox: ~4 hours of human effort. Code must be clean, robust and as simple as possible so every line is easy to justify in a live interview.
